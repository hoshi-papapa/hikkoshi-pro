### タイトル
引越しの達人

### コンセプト
引越のプロセスをスムーズに抜け目なくサポートするアプリ

### 作成したきっかけ
最近引越しをしたことで、引越しを行う際には、「何から手を付けたらいいかわからない」「メッセージアプリでほしいものを共有しても、情報が埋もれてしまう」などの課題があることがわかりました。<br>
そこで、引越しに特化したTodoをあらかじめ設定しておき、使用者は基本的にTodoを作成・期限を設定することなく、引越し日に合わせて何をするべきかわかりやすいアプリを開設しようと思い至りました。<br>
これを利用することで、抜けもれなく引越しがスムーズに行えることが目的です。<br>

### 重視している点
・一人で引越しする場合だけでなく、家族と引越しすることも考えて、一つのメールアドレスで複数のユーザーを作れる<br>
・抜けもれなく引越しができるのをサポート
